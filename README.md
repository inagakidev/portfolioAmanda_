# Portfólio Amanda

> Um portfólio moderno, responsivo e visualmente sofisticado, criado para destacar projetos, experiência profissional e canais de contato com uma identidade tecnológica em tons roxos.

## Sobre o projeto

Este projeto é uma landing page/portfolio desenvolvida com React e Vite, pensada para transmitir uma imagem profissional, elegante e contemporânea. A interface combina elementos visuais futuristas, animações suaves e uma experiência fluida para quem visita o site.

A proposta principal foi criar uma presença digital que seja:
- moderna e visualmente marcante;
- fácil de navegar em diferentes dispositivos;
- inspirada em uma estética tech com destaque para roxo, azul e detalhes luminosos;
- preparada para mostrar projetos, trajetória e formas de contato de maneira impactante.

## O que o projeto oferece

- Layout responsivo e adaptado para desktop e mobile;
- Tema escuro com identidade visual marcante em roxo e ciano;
- Seções bem organizadas para apresentação pessoal, projetos e contato;
- Animações de entrada e efeitos visuais para enriquecer a navegação;
- Suporte a múltiplos idiomas com internacionalização;
- Formulário de contato integrado a uma API para envio de mensagens.

## Tecnologias utilizadas

### Frontend
- React 19
- Vite 8
- CSS Modules para organização dos estilos
- Framer Motion para animações fluidas
- React Icons e Lucide React para ícones
- React i18next para internacionalização
- Swiper para experiências interativas

### Backend e serviços
- Node.js
- Express
- Nodemailer para envio de e-mails
- CORS e express-rate-limit para proteção da API
- dotenv para configuração de ambiente

## Estrutura do projeto

- src/components: componentes reutilizáveis como Header, Hero, Projects, Contact e mais;
- src/context: contexto de tema para alternância visual;
- src/hooks: hooks personalizados para interações e animações;
- src/i18n: arquivos de tradução para inglês e português;
- src/pages: estrutura principal da aplicação;
- backend: API de contato e integração com envio de e-mail.

## Como rodar localmente

### 1. Instale as dependências
```bash
npm install
```

### 2. Inicie o projeto no modo de desenvolvimento
```bash
npm run dev
```

### 3. Para build de produção
```bash
npm run build
```

### 4. Para visualizar a build localmente
```bash
npm run preview
```

### 5. Para o backend de contato
```bash
node backend/server.js
```

> Para o envio de e-mails, é necessário configurar as variáveis de ambiente relacionadas ao servidor de email.
